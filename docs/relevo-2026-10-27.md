# Relevo — Extensión Chrome para seleccionar y anotar web elements

## Objetivo

Extensión de Chrome (MV3) que permite seleccionar uno o varios web elements, anotarlos y entregar ese contexto completo (DOM, estilos, a11y, screenshot, comentario) a agentes de código. Se inspira en el "Design Mode" de [stablyai/orca](https://github.com/stablyai/orca) (licencia MIT, se puede reutilizar código citando la fuente).

## Riesgos ya identificados

- Fibers de React solo se leen desde `world: 'MAIN'`; React 19 eliminó `_debugSource`, así que el archivo:línea de origen saldrá vacío en React 19 salvo con `@babel/plugin-transform-react-jsx-source`.
- `chrome.tabs.captureVisibleTab` solo captura el viewport visible.
- Un puente HTTP/WebSocket a localhost choca con Local Network Access de Chrome (147 lo extendió a WebSocket loopback); Native Messaging lo evita.
